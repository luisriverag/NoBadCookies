# CookiesBeGone

A browser extension that combines automatic cookie banner removal with powerful cookie management.

## Features

- **Auto-remove cookie banners** - Automatically hides GDPR/cookie consent banners
- **Cookie editor** - View, edit, create, and delete cookies from a popup or side panel
- **Whitelist support** - Disable auto-removal for specific domains
- **Export/Import** - Export cookies as JSON, import cookie data
- **Manifest V3** - Modern extension architecture

## Installation

1. Open Chrome/Edge and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select the `CookiesBeGone` folder

## Usage

- Click the extension icon to open the cookie manager
- Use the ⛔ button to toggle auto-removal for the current site
- Search, add, edit, or delete cookies directly from the popup
- Export cookies as JSON for backup or transfer
